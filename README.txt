トラック距離・時間メモ v8（自動保存強化・時刻編集）

更新内容
・入力内容をブラウザ内に自動保存（入力後約0.25秒、画面を離れる際にも保存を試行）
・保存状態を画面上部に表示
・再度開いた際に入力途中のデータを復元
・4つの時刻を時刻入力欄から手動変更可能
・距離入力で時刻を自動記録する動作は維持。ただし既に時刻がある場合は上書きしません
・保存ボタンで記録一覧に確定保存

GitHub Pagesの更新方法
1. 先にアプリ内の「CSVを書き出す」でバックアップしてください。
2. ZIPを展開し、index.html と sw.js をGitHubの truck-memo リポジトリで置き換えます。
3. Commit changes を押して、公開反映まで数分待ちます。
4. アプリを再読み込みしてください。

注意：自動保存はこの端末・ブラウザ内です。ブラウザのサイトデータ削除、プライベートブラウズ終了、端末故障などに備えて、定期的にCSVを書き出してください。
